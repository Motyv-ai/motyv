# Motyv для Claude Code

Плагін підключає [Motyv](https://motyv.ai) до Claude Code: судова практика України
(правові позиції Верховного Суду й апеляції з цитатами, рішення всіх судів із реєстру,
судді й суди), законодавство (акти Ради, редакції, практика за статтею), листи органів,
практика ЄСПЛ проти України і перевірка контрагентів (ЄДР, суди, боржники, санкції).

## Встановлення

```bash
claude plugin marketplace add Motyv-ai/claude-plugin
claude plugin install motyv@motyv
```

або в самому Claude Code: `/plugin` → **Add marketplace** → `Motyv-ai/claude-plugin`.

Під час першого звернення до Motyv відкриється браузер для входу у ваш акаунт Motyv
(OAuth). Паролів і ключів плагін не зберігає. Потрібен акаунт на [motyv.ai](https://motyv.ai) —
пробний період безкоштовний.

## Що всередині

- `.mcp.json` — MCP-сервер `https://mcp.motyv.ai/mcp`: пошук позицій ВС, дослівний пошук
  у текстах, реєстр рішень, судді, закони, контрагенти, «Обране».
- `skills/motyv/SKILL.md` — скіл: як шукати і як відповідати юристу (посилання на справу й
  дату, чесне «у базі не знайдено» замість «практики немає»).

## Приклади питань

- «Яка практика ВС щодо стягнення 3 % річних за ст. 625 ЦК при простроченні держави?»
- «Покажи рішення судді Іваненко І. І. Печерського районного суду у трудових спорах»
- «Перевір ТОВ з кодом 12345678: суди, боржники, санкції»
- «Прочитай ст. 10 Закону № 2493 і дай практику до неї»

## Інші клієнти

Той самий MCP-сервер працює в claude.ai (Settings → Connectors → Add custom connector →
`https://mcp.motyv.ai/mcp`), ChatGPT і Codex.

Питання й відгуки — support@motyv.ai або [@motyv_supportbot](https://t.me/motyv_supportbot).
